MulmoClaude のインストール

この手順書では、Mac に Docker Desktop と MulmoClaude を入れ、ブラウザで使い始めるまでを説明します。上から順に進めてください。目安は20〜30分です。

先にMulmoClaude を使う前の準備を済ませてください。画面の図はすべてイメージで、実際の表示とは少し違うことがあります。

  • Docker Desktop を入れるか決める
  • ステップ 1　Docker Desktop を入れる
  • ステップ 2　MulmoClaude を起動する
  • ステップ 3　アイコンから起動できるようにする
  • うまくいかないとき

Docker Desktop を入れるか決める

Claude Code が Mac でできること

Claude Code は、Bash（Mac を操作するツール）などを使って、あなたの Mac のファイルを読んだり書いたり、コマンドを実行したりできます。

Docker Desktop で変わること

Docker Desktop がないと、Claude Code はあなたのアカウントで開けるファイルすべてに手が届き、SSH の鍵や作業用フォルダの外に保存された認証情報（パスワードなど）も含まれます。MulmoClaude の公式の説明は、個人の PC で使う分には許容範囲としつつ、知っておくべきことだとしています。

Docker Desktop があると、MulmoClaude は起動時に自動で見つけ、設定なしで Claude Code を「サンドボックス」という囲いの中で動かします。囲いの中の Claude Code が直接読み書きできるのは作業用フォルダ（~/mulmoclaude）と Claude Code 自身の設定（~/.claude）だけで、それ以外は見えず、作業用フォルダに書いたものは Mac の本物のファイルとして残ります。

どうするか

Docker Desktop を入れることをおすすめします。ステップ1へ進んでください。

注意Docker Desktop は個人・教育や小さな事業者（従業員250人未満、かつ年間売上1,000万ドル未満）では無料ですが、それより大きな会社で仕事に使う場合は有料契約が必要なので、会社の PC で利用する場合は管理者に確かめてください。
入れないと決めたとき

ステップ1を飛ばしてステップ2へ進んでください（MulmoClaude は動きますが、画面上部の鍵が黄色の開いた鍵になり、Docker 未検出を示します）。

ステップ 1Docker Desktop を入れる

ここでは、Claude Code をサンドボックスの中で動かすために、Docker Desktop をインストールします。

1Mac のチップを確かめる

画面左上のアップルメニューから「この Mac について」を開きます。「チップ」に Apple M1 などとあれば Apple シリコン、「プロセッサ」に Intel とあれば Intel です。

2ダウンロードする

ブラウザで https://www.docker.com/products/docker-desktop/ を開き、「Download Docker Desktop」から、1-1 で確かめたチップに合う「Download for Mac - Apple Silicon」か「Download for Mac - Intel Chip」を選びます。Docker.dmg がダウンロードされます。

3アプリケーションに入れる

ダウンロードフォルダの Docker.dmg をダブルクリックし、出てきた窓で Docker のアイコンを「Applications」フォルダへドラッグします。

4Docker を起動する

command+スペースで検索窓を出し、「Docker」と打って return を押します。

開いてもよいか聞かれたとき

インターネットから入れたアプリなので確認が出ます。「開く」を押してください。

5利用規約に同意する

「Docker Subscription Service Agreement」が出たら「Accept」を押します。

サインインやアンケートの画面が出たとき

サインインしなくても使えます。「Skip」を押して進んでください。

6起動が終わるのを待つ

画面上のメニューバーにあるクジラのアイコンは、動いている間は起動中です。動きが止まるまで待ちます。

確認クジラのアイコンが止まっていれば、ステップ1は完了です。

ステップ 2MulmoClaude を起動する

1起動のコマンドを貼る

ターミナルに次のコマンドを貼って return を押します。初めてのときは「Need to install the following packages:」「Ok to proceed? (y)」と聞かれます。

npx mulmoclaude@latest

2y を押して return

y を押して return を押します。必要なもののダウンロードと、初回は Docker の準備に数分かかります。

確認「✓ MulmoClaude is ready」が出れば起動完了です。
注意このターミナルの窓を閉じると MulmoClaude も止まるので、使っている間は開いたままにしてください。

3ブラウザで開く

起動すると、ブラウザで MulmoClaude（http://localhost:3001）が自動で開きます。

ブラウザが開かないとき

ブラウザで http://localhost:3001 を開きます。ターミナルに別の番号（例：3002）の URL が出ていれば、そちらを開いてください。

4画面の見方

図の①〜⑥は、画面の各部を示しています。いちばんよく使うのは、左下の入力欄です。

5鍵のアイコンを確かめる

画面上部の鍵のアイコンを見ます。灰色の閉じた鍵なら、Docker のサンドボックスで動いています。鍵を押すと「サンドボックス有効」と表示されます。

黄色の開いた鍵のとき

Docker が見つかっていません（「サンドボックスなし (Docker 未検出)」）。Docker Desktop が起動しているかクジラのアイコンで確かめ、ターミナルで control+C を押して MulmoClaude を止めてから、2-1 のコマンドでもう一度起動してください。

6話しかける

左下の入力欄（「Claude にメッセージ…」）に、たとえば「何ができるか教えて」と日本語で打って送ります。

確認返事が表示されれば完了です。
メモ使い終わるときやステップ3へ進むときはターミナルで control+C を押し、次にコマンドから使うときは 2-1 のコマンドで起動します。

ステップ 3アイコンから起動できるようにする

毎回ターミナルにコマンドを打たずに、アプリのアイコンをダブルクリックして起動できるようにする、1回だけの設定です。

1アイコンを作る

ターミナルに次のコマンドを貼って return を押します。「Create /Applications/MulmoClaude.app? [Y/n]」と聞かれたら、そのまま return を押します。

npx mulmoclaude@latest create-shortcut

2アイコンから起動する

アプリケーションフォルダ（または Launchpad）の「MulmoClaude」をダブルクリックします。起動の準備が終わると、ブラウザで MulmoClaude が開きます。

メモMulmoClaude を新しい版に更新したら、3-1 のコマンドをもう一度実行してください。

うまくいかないとき

画面に出た文字意味と対処
command not found: npxNode.js が入っていません。「MulmoClaude を使う前の準備」のステップ2へ戻ってください。
Claude Code CLI not found.Claude Code が入っていないか、見つかりません。「MulmoClaude を使う前の準備」のステップ3へ戻ってください。
Port 3001 busy → using 3002 instead.3001 番がほかで使われています。表示された URL（例：http://localhost:3002）を開いてください。
鍵のアイコンが黄色の開いた鍵になっているDocker Desktop が起動していません。2-5 の「黄色の開いた鍵のとき」を見てください。
npx が長く止まる、ETIMEDOUT や ECONNRESET が出る会社のネットワークで npm の配布サイトへの接続が止められている可能性があります。「MulmoClaude を使う前の準備」の「管理者に伝えること」を見て、registry.npmjs.org を含めて管理者に相談してください。
初回の起動でサンドボックスの準備のところで止まる・失敗する会社のネットワークで Docker の部品のダウンロードが止められている可能性があります。画面を撮って管理者に相談してください。

画面はすべてイメージ図です。実際の表示は Mac の設定やソフトウェアの版によって少し違います。
